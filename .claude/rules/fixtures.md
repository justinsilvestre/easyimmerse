# Fixtures

- Media files are generated by `fixtures/generate-media.sh`. Never edit them by hand; change the script and regenerate.
- Text fixtures are hand-written. Keep the SRT and VTT files in sync with each other and with the subtitle track inside the video.
- Every fixture stays under 200 KB so the repository stays small.
- Whole books are committed only in compressed form: plain text as `.gz`, which every tool that reads it unpacks first by calling `unpackFixtures`, and EPUB trees only as the packaged `.epub`. Add each unpacked path to `.gitignore`.
- Each fixture is documented in the Fixtures section of the root `README.md`.
