# easyImmerse

A free cross-platform software suite for learning languages through native media.
See the [overview](docs/overview.md) for an introduction to the project.

## Repository structure

| Folder | Contents |
| --- | --- |
| [apps/web](apps/web) | The web app, a Progressive Web App built with Vite. |
| [apps/native](apps/native) | The desktop and mobile apps, built with Tauri. The desktop app bundles the server. |
| [apps/extension](apps/extension) | The browser extension for Chrome and Firefox. |
| [apps/server](apps/server) | The standalone server, a command-line program. |
| [packages/client](packages/client) | The user interface and state management shared by all apps, with Storybook. |
| [packages/api](packages/api) | The API server built with Fastify, and its database access built with Drizzle. |
| [packages/media](packages/media) | The processing of video, audio, subtitles, and ebooks. |
| [docs](docs) | The product documentation. |

Packages are consumed by the apps directly as TypeScript source code, so they have no build step.

## Architecture

All apps render the same React user interface from `packages/client`.
The state of the user interface is held in a Redux store and changed by one pure function, `updateApp`.
This function returns the next state together with a list of _effects_,
which are plain objects describing the side effects to carry out.
A middleware passes each effect to the _effects runners_ of the current platform.
Each app provides its own effects runners when starting the user interface,
so the shared code never depends on platform-specific features.

Communication with the API server happens through RTK Query.

The desktop app runs the API server on the user's device.
The server is bundled with the app as a JavaScript file, along with a copy of the Node executable that runs it.

## Requirements

- [Mise](https://mise.jdx.dev), which installs the pinned versions of Node and pnpm
- [Rust](https://rustup.rs) and the [prerequisites of Tauri](https://tauri.app/start/prerequisites/), for the desktop and mobile apps
- [ffmpeg](https://ffmpeg.org), for media processing

## Getting started

```sh
mise install
mise exec -- pnpm install
```

The commands below are to be run through Mise as well, by prefixing them with `mise exec --` or by activating Mise in your shell.

| Command | Purpose |
| --- | --- |
| `pnpm dev:server` | Runs the server at http://localhost:4100. |
| `pnpm dev:web` | Runs the web app, which expects a running server. |
| `pnpm dev:native` | Runs the desktop app. Requires the steps under "Desktop app" below. |
| `pnpm storybook` | Runs Storybook. |
| `pnpm check` | Checks formatting and lint rules with Biome. |
| `pnpm typecheck` | Checks types in all packages. |
| `pnpm test` | Runs the unit tests of all packages with Vitest. |
| `pnpm build` | Builds the web app, the browser extension, and the server. |

### End-to-end tests

The end-to-end tests run against the built apps and the built server.

```sh
pnpm build
pnpm --filter @easyimmerse/web exec playwright install
pnpm --filter @easyimmerse/web test:e2e
pnpm --filter @easyimmerse/extension test:e2e
```

### Desktop app

The desktop app bundles the built server, so the server must be built and copied before the app.

```sh
pnpm --filter @easyimmerse/server build
pnpm --filter @easyimmerse/native prepare-sidecar
pnpm --filter @easyimmerse/native build:app
pnpm --filter @easyimmerse/native smoke-test
```

### Mobile apps

The Android and Xcode projects are generated by Tauri and are not stored in the repository.

```sh
pnpm --filter @easyimmerse/native tauri android init
pnpm --filter @easyimmerse/native tauri android dev
```

Replace `android` with `ios` for the iOS app.

### Database migrations

After changing the database schema in `packages/api/src/database/schema.ts`, generate a migration:

```sh
pnpm --filter @easyimmerse/api generate-migrations --name <description_of_change>
```
