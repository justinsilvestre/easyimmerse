# Japanese deinflection fixtures

Test oracles for the Japanese deinflector. Each fixture lists inflected forms with the dictionary form and word class the deinflector must recover. The oracles only check the rules; they are not the sources the rules are drawn from (see `docs/japanese-deinflection-sources.md`).

| File | Generated by | Source | Licence |
|---|---|---|---|
| `kamiya-cases.json` | `generate-kamiya-cases.cjs` | kamiya-codec 4.16.1 | Unlicense (public domain) |
| `unidic-cases.json` | `generate-unidic-cases.cjs` | 現代書き言葉UniDic ver. 2025.12 (`unidic-cwj-202512`) | BSD 3-Clause, in `LICENSE-UniDic` |

Each script names the command that regenerates its fixture. Neither package is a dependency of the repository; install or download it outside the repository first.

## UniDic

`unidic-cases.json` is derived from 現代書き言葉UniDic ver. 2025.12, the lightweight package `unidic-cwj-202512.zip` from <https://clrd.ninjal.ac.jp/unidic/>.

- UniDic ver. 2025.12 ships no AUTHORS file; the copyright holder and implementor above are those named in its `README.md`.

The fixture holds one row per conjugated form (活用形) of a chosen word, or of an auxiliary verb after a word, as `[inflected form, dictionary form, word class, UniDic conjugation type and form]`. A form that cannot end a word is followed by what UniDic connects to it, such as ない after the irrealis form. The script leaves out dialect, archaic and emphatic spellings, and lists each kind it leaves out.
